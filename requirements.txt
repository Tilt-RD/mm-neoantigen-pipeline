# Streamlit Community Cloud installs from this file.
#
# It deliberately contains ONLY what app.py imports. The dashboard imports
# streamlit, pandas, numpy and plotly and nothing else: it does not import
# pysam, py3Dmol, fpdf2 or biopython at module level or lazily.
#
# Those four were previously listed here and are the reason deploys were slow
# and fragile. pysam is a C extension that compiles against htslib and is a
# common cause of Streamlit Cloud build failures; installing it to run a
# dashboard that never imports it buys nothing.
#
# The full pipeline dependency set lives in requirements_pipeline.txt. Install
# that one for local pipeline runs:
#
#     pip install -r requirements_pipeline.txt
#
# MHCflurry is in the pipeline file rather than here, and is effectively
# required for any binding number to be interpretable. The built-in PSSM
# fallback covers four alleles and is a rough approximation.
